# Banking Customer Risk & Loan Portfolio Intelligence

## Project Overview
An end-to-end banking analytics project focused on analyzing customer profiles, loan applications, and financial risk indicators using Power BI and Python.

## Problem Statement
Banks need to analyze customer financial profiles and loan-related information to better understand customer characteristics and lending risks. This project explores banking data to generate insights that can support informed lending decisions.

## Objectives
- Analyze customer profiles and loan application trends.
- Examine income, credit scores, and loan amounts.
- Develop KPIs and interactive Power BI dashboards.
- Explore time-based patterns using Python.
- Present insights through clear data visualizations.

## Tools & Technologies

- SQL (include if used)

## Project Workflow
